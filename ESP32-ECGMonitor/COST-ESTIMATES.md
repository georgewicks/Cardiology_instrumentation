# Cost estimation

# Component breakout board costs
The list of basic component boards

* ESP32-S3-WROOM DevKit: $10.00
* ADS1115 Breakout board: $7.00
* AD8232 Physiological Monitor: $5.00
* DS3231 RTC Breakout board: $5.00
* MicroSD 8GB Adapter: $5.00

In addition, there are power supply components, including a LIPO battery, a DC-DC converter, and a battery charger. The total cost for these components is about $15.00.

Ball-park cost for the basic prototype is about $50.00, not including the cost of the PCB, which is TBD. The PCB will be designed to accommodate SMD components, and will be a custom design. The cost of the PCB will depend on the number of layers, the size, and the quantity ordered. A rough estimate for a 2-layer PCB with a size of 2" x 2" is about $5.00 per board for a quantity of 10 boards.
